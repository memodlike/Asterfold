# Asterfold — листинг Chrome Web Store (русский)

## Название

Asterfold

## Краткое описание

Локальное визуальное пространство для организации и открытия закладок в каждой новой вкладке Chrome.

Количество символов: 100 с пробелами.

## Подробное описание

Asterfold заменяет новую вкладку Chrome спокойным визуальным пространством для сайтов, которыми вы пользуетесь каждый день.

Разложите закладки по Страницам и Блокам и открывайте их прямо из новой вкладки. Поиск, Quick Save, перетаскивание, Корзина, импорт и экспорт помогают одной цели — быстро находить полезные ссылки без отправки рабочего пространства на сервер Asterfold.

### Организация

- Создавайте Страницы для работы, учёбы и личных проектов.
- Собирайте связанные закладки в визуальные Блоки.
- Перемещайте Блоки и закладки мышью или клавиатурой.
- Выбирайте режим открытия каждой закладки: текущая вкладка, новая вкладка или новое окно.

### Поиск и сохранение

- Ищите по названию или URL внутри локального пространства.
- Используйте Quick Save после явного действия в панели расширений, горячей клавиши или контекстного меню.
- Импортируйте дерево закладок Chrome только после добровольного предоставления опционального разрешения.
- Экспортируйте и восстанавливайте версионные локальные резервные копии.
- Возвращайте удалённые записи из Корзины до окончательной очистки.

### Внешний вид

- Светлая, тёмная или системная тема.
- Встроенный фон или обои, хранящиеся локально.
- Настройка компоновки и эффекта стекла.
- Режимы Balanced и Low Power для разных компьютеров.
- 12 выбираемых языков интерфейса; редкие непереведённые строки во второстепенных локалях могут безопасно отображаться на английском.

### Приватность

Asterfold 3.0.1 работает по принципу local-first. Данные рабочего пространства находятся в локальном профиле Chrome. В стандартной версии нет backend, аккаунта, аналитики, рекламы, телеметрии, облачной синхронизации, host permissions и content scripts; расширение не выполняет собственных сетевых запросов.

Chrome может использовать сеть, когда вы открываете сайт или когда браузер предоставляет собственный favicon-ресурс. Privacy Mode скрывает названия закладок в интерфейсе и локальном поиске, пока режим включён, но является визуальной защитой, а не шифрованием базы.

## Разрешения

- `activeTab`: читает название и URL страницы только после запуска Quick Save или поддерживаемого действия сохранения.
- `favicon`: показывает favicon из принадлежащего Chrome ресурса для сохранённого URL.
- `alarms`: запускает локальную очистку Корзины по выбранному сроку хранения.
- `contextMenus`: добавляет команды «Сохранить страницу», «Сохранить ссылку» и «Открыть Asterfold».
- `storage`: хранит только временный флаг Privacy Mode в хранилище сессии Chrome, чтобы popup и новая вкладка работали согласованно; Chrome очищает его после завершения сессии браузера.
- опциональное `bookmarks`: запрашивается только при выборе импорта закладок Chrome.

Доступ к истории браузера, cookies, содержимому всех сайтов и host origins не запрашивается.
