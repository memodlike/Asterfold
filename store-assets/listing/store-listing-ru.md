# Asterfold — листинг Chrome Web Store (русский)

## Название

Asterfold — закладки на новой вкладке и визуальный Speed Dial

## Краткое описание

Новая вкладка с визуальными досками закладок: экспресс-панель, быстрый поиск, обои. Без аккаунта и без слежки.

Количество символов: 110 с пробелами. Тот же текст поставляется в `public/_locales/ru/messages.json`.

## Подробное описание

Текст ниже вставляется в Dashboard без изменений. Chrome Web Store показывает только простой текст, без Markdown: пункты — это символ «•», заголовки — обычные строки.

```text
Asterfold превращает каждую новую вкладку в спокойную визуальную доску с сайтами, которые вы открываете чаще всего. Нужная ссылка всегда в одном клике.

Хватит искать нужное в панели закладок и среди 40 открытых вкладок. Разложите рабочие, учебные и личные ссылки по Страницам, сгруппируйте их в Блоки и открывайте нужное сразу, как только появилась новая вкладка.

ЧТО ВНУТРИ
• Визуальная экспресс-панель: закладки плитками с иконками сайтов, сгруппированные в Блоки
• Страницы под каждый контекст: работа, учёба, проекты, дом
• Мгновенный поиск: нажмите Ctrl+K (⌘K на Mac) и наберите пару букв
• Открыть целый Блок разом, во вкладках или в новом окне
• Перетаскивание мышью или управление с клавиатуры
• Вставьте ссылку на страницу, и закладка сохранится за секунду
• Корзина с отменой: ничего не пропадёт случайно
• Светлая, тёмная и системная темы, встроенные обои или своё фото, блоки из матового стекла
• Плавно на любом компьютере: облегчённый режим для слабых ноутбуков
• 17 языков интерфейса

ПЕРЕЕЗД ЗА МИНУТУ
1. Установите Asterfold и откройте новую вкладку. Экран приветствия откроется сам.
2. Начните с готового пространства или перенесите закладки Chrome: Chrome сохраняет их в файл, Asterfold читает этот файл. Внутри есть инструкция из трёх шагов.
3. Если Chrome спросит, вернуть ли прежнюю новую вкладку, оставьте Asterfold.

ПРИВАТНОСТЬ ПО УМОЛЧАНИЮ
• Без аккаунта, регистрации и облака
• Без аналитики, рекламы и слежки
• Asterfold не запрашивает никаких разрешений: он не видит страницы, которые вы открываете, и историю браузера
• Всё хранится в вашем профиле Chrome; резервную копию можно выгрузить в файл в любой момент
• Режим приватности скрывает названия закладок, когда кто-то смотрит через плечо

Иконки сайтов загружаются напрямую с сайтов из ваших закладок; их можно отключить в настройках.

Бесплатно. Исходный код на GitHub. Вопросы и идеи: https://github.com/memodlike/Asterfold/issues
Политика конфиденциальности: https://github.com/memodlike/Asterfold/blob/main/docs/security/privacy.md

Новое в 3.9.2: экран приветствия открывается сразу после установки, название и описание показываются на вашем языке, а через неделю использования появляется приглашение оценить Asterfold — не чаще раза за выпуск, его легко закрыть.
```

## Разрешения

Asterfold не запрашивает никаких разрешений: `permissions`, `optional_permissions` и `host_permissions` пусты.

Доступ к истории браузера, cookies и host origins не запрашивается.
