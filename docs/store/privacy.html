Asterfold Privacy Policy

Effective 26 July 2026 · Policy version 2.2.2

Asterfold is a local-first bookmark workspace. It processes bookmark and workspace information on the user's device to provide its features. It does not claim that no data is processed.

Information processed

Asterfold may process bookmark URLs and titles, Pages, Boards, order, opening mode, settings, Trash records, Quick Save destinations, imported bookmark data, local backups, uploaded wallpaper images and local raster icons. This content may be personal if the user chooses to store personal information in it.

Storage and network behavior

Workspace records and uploaded assets are stored locally in the user's Chrome profile, primarily in IndexedDB. Search, import preview and backup processing run locally. Asterfold 2.2.2 has no application backend, account or cloud synchronization. The default build has no host permissions and makes no application network requests. Data is not sent to the developer.

Chrome may independently use the network when the user opens a destination page or when Chrome supplies its browser-owned _favicon resource. Asterfold does not store or render remote favicon URLs.

Use of information

Local information is used only to display, organize, search, open, import, export, restore and maintain the user's bookmark workspace, including Quick Save, Trash and optional local appearance assets.

No sale, advertising or analytics

Asterfold does not transmit user data to the developer, sell or share user data, run advertising or affiliate tracking, build user profiles, use analytics or telemetry, or allow developer personnel to read the local workspace. It uses no remote scripts or executable code.

Quick Save and Chrome bookmarks

Quick Save reads the active page URL and title only after the user invokes the toolbar action, keyboard command or supported context-menu action. It saves that information locally.

The optional bookmarks permission is requested only when the user chooses to import Chrome bookmarks. If granted, the Chrome bookmark tree is read and processed locally to create an import preview. Declining it does not affect the normal workspace or file import/export.

Imports, backups and deletion

Imported files are validated locally and are not uploaded. Exported backups can contain bookmark URLs, titles, structure, settings and supported local assets, so users should protect them as personal files.

Users can delete items, empty Trash, remove local extension data, or uninstall the extension. A backup should be exported first if the records matter.

Wallpapers and icons

User-selected wallpapers and custom icons are decoded, bounded and stored locally. Asterfold rejects remote image URLs and SVG files as local custom icons.

Privacy Mode

Privacy Mode hides titles from the rendered interface and accessible labels, disables clipboard actions and prevents creation of the local search index while active. It is visual shoulder-surfing protection, not encryption. The local database remains accessible to the Chrome profile, operating system or anyone controlling the device.

Children

Asterfold is a general-purpose productivity tool and is not directed specifically to children. Version 2.2.2 has no developer-operated service that collects user information.

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes and contact

Material changes to data practices require an updated effective date and policy before release. Questions can be submitted through the public issue tracker. The source policy is available in the public repository.
