# Asterfold 3.1.4 physical test plan

Target environment: Windows 11, Chrome 120+, AMD Radeon R5 230 / Caicos or equivalent legacy GPU.

## Verified test package

- File: `Asterfold-Chrome-v3.1.4-Opaque-Settings-Test.zip`
- Manifest: MV3, version `3.1.4`, minimum Chrome `120`
- SHA-256: `5442bf0e2cf9b9cd63750fe8882b312094dcb7dd3e4fdb6b76264d515b681458`

## Installation safety

1. Export an Asterfold JSON backup from the currently installed version.
2. Keep the existing unpacked extension folder until the test is complete.
3. Extract `Asterfold-Chrome-v3.1.4-Opaque-Settings-Test.zip` and load the folder containing `manifest.json` through `chrome://extensions` → Developer mode → Load unpacked.

## Required checks

- Open Settings in light, dark and auto theme modes. The Settings shell, cards, inputs, menus and dropdowns must be fully opaque.
- Open Search, Rename, Add bookmark, Move, Quick Save, launcher and context menus. No wallpaper or workspace content may bleed through their surfaces.
- Open each custom dropdown with pointer and keyboard. Verify Arrow keys, Home, End, Enter, Space, Escape, Tab and typeahead.
- Verify each language displays a local SVG country flag rather than a text country code or operating-system emoji.
- Move every Appearance slider. Preview must update immediately and remain after Settings is closed and reopened.
- Test background mode, glass style, transparency, blur, dimming, wallpaper blur and saturation.
- Confirm Compatibility mode avoids live backdrop blur and remains responsive on the Radeon R5 230 path.
- Open and close the launcher twenty times, search repeatedly and move bookmarks between Boards. No frozen controls, transparent popovers or persistent focus traps are allowed.
- Confirm existing Pages, Boards, Bookmarks, wallpaper and settings remain intact after upgrading from the previous installation.

## Release boundary

PR #38 remains Draft and must not be merged into `main`, tagged or published until this physical test is accepted.
