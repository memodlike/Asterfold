# Asterfold 3.1.4 physical test plan

Target environment: Windows 11, Chrome 120+, AMD Radeon R5 230 / Caicos or equivalent legacy GPU.

## Verified test package

- GitHub Actions artifact: `release-linux` from the latest successful CI run for PR #38.
- Inner runtime package: `Asterfold-Chrome.zip`.
- Runtime package size: `4,340,460` bytes.
- Runtime package SHA-256: `d1708fa43b41a6695c7b8eac7748a065e19d263ab2fa587476374930349743ad`.
- Manifest: MV3, version `3.1.4`, minimum Chrome `120`.
- Runtime archive: 40 entries with deterministic `2020-01-01 00:00` timestamps.
- Automated MV3 tests select Page, Board and Move destinations through the visible custom listbox rather than a native-select shortcut.
- Visual E2E requires solid menu surfaces: `rgb(255, 255, 255)` in light mode and `rgb(45, 47, 52)` in dark mode; translucent fallbacks are rejected.

The SHA-256 above identifies the exact runtime package approved for physical testing. Do not substitute GitHub's automatically generated source-code archives.

## Installation safety

1. Export an Asterfold JSON backup from the currently installed version.
2. Keep the existing unpacked extension folder and previous stable archive until the test is complete.
3. Download and extract the `release-linux` workflow artifact.
4. Verify the SHA-256 of the inner `Asterfold-Chrome.zip`.
5. Extract `Asterfold-Chrome.zip` into a permanent folder.
6. Open `chrome://extensions` → enable Developer mode → select Load unpacked.
7. Select the extracted folder that contains `manifest.json`.
8. Record the loaded extension version, Chrome version and renderer string from `chrome://gpu`.

## Required checks

- Open Settings in light, dark and auto theme modes. The Settings shell, cards, inputs, menus and dropdowns must be fully opaque.
- Open Search, Rename, Add bookmark, Move, Quick Save, launcher and context menus. No wallpaper or workspace content may bleed through their surfaces.
- Open each custom dropdown with pointer and keyboard. Verify Arrow keys, Home, End, Enter, Space, Escape, Tab and typeahead.
- Verify each language displays a local SVG country flag rather than a text country code or operating-system emoji.
- Move every Appearance slider. Preview must update immediately and remain after Settings is closed, reopened and the new tab is reloaded.
- Test background mode, glass style, transparency, blur, dimming, wallpaper blur and saturation.
- Confirm Compatibility mode avoids live backdrop blur and remains responsive on the Radeon R5 230 path.
- Open and close the launcher 50 times, Settings 50 times, Search 50 times and custom dropdowns 100 times. No frozen controls, transparent popovers, stale portals or persistent focus traps are allowed.
- Confirm existing Pages, Boards, Bookmarks, wallpaper, locale, privacy state, Quick Save destinations and settings remain intact after upgrading from the previous installation.
- Confirm `chrome://extensions` shows no extension errors and the browser console has no uncaught errors or unhandled rejections.

## Evidence to record

- Windows edition and build;
- Chrome version;
- `chrome://gpu` renderer string;
- exact `Asterfold-Chrome.zip` SHA-256;
- screenshots of Settings, Search, Add Bookmark, Move, launcher and context menu over a high-contrast wallpaper;
- observed interaction latency or freezes in Quality, Compatibility and Software modes;
- pass/fail result for upgrade data preservation.

## Release boundary

PR #38 remains Draft and must not be merged into `main`, tagged or published as a stable release until this physical test is accepted. Chrome Web Store submission remains outside this test plan and requires separate owner authorization.
